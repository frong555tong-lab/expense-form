ใบสำรองจ่ายแทนบริษัท — เว็บแอปแบบ static

กรอกเอกสาร เพิ่ม/ลบรายการ แล้วกดพิมพ์เอกสารเพื่อพิมพ์ A4 หรือบันทึก PDF
จำนวนเงินเป็นบาท ทศนิยมไม่เกิน 2 ตำแหน่ง ไม่ติดลบ ยอดรวมไม่เกิน 999,999,999.99 บาท
ผู้รับเงินคืนเว้นว่างได้ ระบบใช้ชื่อผู้สำรองจ่ายในช่องลงนามแทน

ความเป็นส่วนตัว
- ไม่มีบริษัท บุคคล หรือข้อมูลติดต่อจริงฝังในชุดไฟล์นี้
- ประมวลผลข้อมูลฟอร์มในเบราว์เซอร์ ไม่มี backend, analytics, ฟอนต์ภายนอก หรือการส่งข้อมูลฟอร์ม
- ผู้ให้บริการโฮสต์ยังเห็นคำขอเปิดเว็บ/IP ตามการให้บริการปกติ
- เริ่มต้นไม่บันทึกฟอร์ม เลือกจำเฉพาะบริษัท ผู้สำรองจ่าย ตำแหน่ง ผู้รับเงินคืนได้
- ตัวเลือกบันทึกร่างแยกต่างหากจะเก็บข้อมูลทั้งหมดที่กรอก รวมหมายเหตุ ไม่ควรใส่ข้อมูลธนาคาร/ภาษี/ติดต่อที่ไม่จำเป็น
- localStorage ไม่เข้ารหัส ผู้ใช้โปรไฟล์เบราว์เซอร์เดียวกัน/สคริปต์บน origin เดียวกันอาจเข้าถึงได้
- ไม่ซิงก์ข้ามเครื่อง ไม่ใช่ระบบสำรองข้อมูล การล้างเบราว์เซอร์อาจทำให้ข้อมูลหาย
- PDF ที่บันทึกมีข้อมูลที่กรอก เก็บ PDF และหลักฐานค่าใช้จ่ายให้ปลอดภัย

ปุ่มเอกสารใหม่: ยืนยันก่อนล้างรายละเอียด คงบริษัท/ชื่อ/ตำแหน่งในฟอร์ม
ปุ่มล้างข้อมูลทั้งหมด: ยืนยันก่อนล้างฟอร์มและที่เก็บของแอปนี้ ไม่ลบแอปอื่นหรือ PDF
ยกเลิกการยืนยันจะไม่เปลี่ยนแปลงข้อมูล ตัวเลือกบันทึกจะคงอยู่จนยกเลิกหรือล้างข้อมูล
ไม่อ่านหรือย้ายข้อมูลของแอปเวอร์ชันเดิมโดยอัตโนมัติ

โฮสต์: วางไฟล์ทั้งหมดและโฟลเดอร์ icons บน static hosting HTTPS เช่น GitHub Pages
เว็บ/โค้ดที่เผยแพร่เป็นสาธารณะ ทุกคนเปิดได้ แต่ไม่ได้รับข้อมูลฟอร์มของคุณ
ติดตั้ง PWA จากเมนูเบราว์เซอร์ได้เมื่อใช้ HTTPS (หรือ localhost สำหรับทดสอบ)
เปิด file:// ใช้กรอก/พิมพ์ได้ แต่ไม่รองรับติดตั้ง/ออฟไลน์ และที่เก็บข้อมูลขึ้นกับเบราว์เซอร์
หลังเปิดออนไลน์ครั้งแรก แคชเฉพาะไฟล์แอปสำหรับออฟไลน์
อัปเดตไฟล์: เพิ่มหมายเลข CACHE ใน sw.js ด้วย ปิดแท็บแอปทุกแท็บแล้วเปิดใหม่เพื่อรับเวอร์ชันใหม่
ไม่มีการบังคับรีโหลดขณะกรอก เก็บ PDF ก่อนปิดหากไม่ได้เลือกบันทึกร่าง
ควรโฮสต์แยก origin จากแอปที่ไม่เชื่อถือ และไม่ใช้บนเครื่องสาธารณะ
